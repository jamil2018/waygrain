# ADR-002 — Opt-in compact capture retrieval

Selected 14 October 2026 for G06; bounded implementation under independent review. This is an explicit amendment to the v0.2 `wg_query` contract. Historical ADR-001 and specification bytes remain unchanged.

G05's capture-only study did not beat notes. In 30 warm Waygrain sessions, only three consulted memory; 51 live snapshots remained, with four memory searches and six reads. G06 removes a retrieval round trip where capture evidence is sufficient; it does not qualify saved evidence for current UI actions or reverse G05's failed gates.

Use `wg_query` with `mode: "search"`, `projection: "compact"` and `filters.kinds: ["capture"]`. Existing lexical screen-name/tag/ID matching and ranking remain unchanged; this is not full-tree text search. Compact projection is rejected for other kind combinations and other modes. Omit projection to retain the original response. No new tool, store migration or browser invocation is introduced. `wg_evidence` retains full structured inspection and its existing defaults.

Each capture record optionally contains `compact.source_id`, `compact.view_path` (`/view`), the stored sanitized `view`, and up to 16 tree nodes in stored preorder. Nodes contain exact role, name, enabled, visible, optional selected, and `source_path`, a JSON Pointer rooted in the stored capture returned by structured `wg_evidence`. Cite the source ID together with that pointer. These pointers are data locations, never executable selectors or browser targets. Locator hints and raw data are excluded. Names over 256 UTF-8 bytes are omitted entirely; omitted nodes and NODE_LIMIT/TEXT_LIMIT reasons are explicit. This first slice returns small tree prefixes, not a generated answer or relevance-ranked excerpts within a capture.

The enclosing record preserves its capture's scope, source metadata, provenance, coverage and freshness: observation/check time, age, known-or-null application version, scope match and recent/stale/contradicted/unknown status. No newer record lends freshness to an older capture. Search applicability remains requires_check. Recent is an age-policy verdict, not current applicability. Partial coverage and omitted excerpts cannot establish absence. Retrieval never advances check times or writes to the store.

Existing whole-envelope record/byte limits and cursors apply. Each enriched record fits atomically or is withheld with explicit incomplete/BUDGET_EXCEEDED semantics; citations and safety metadata are never stripped to fit. Projection participates in cursor binding; writes invalidate cursors. Inner compact omissions are separate from outer query continuation, which pages matching records and does not page omitted tree nodes. Use structured evidence for additional detail.

The [G06 protocol](../../tasks/evidence/g06/PROTOCOL.md) binds acceptance and comparison. Retrieval-only calls/serialized bytes/local timing cannot establish model token savings, end-to-end scout efficiency or superiority over notes. No measured release requirement is waived. Claude Code/Cursor remain deferred/unverified; original human adoption and second application unmet/unverified; public release HOLD. No commit, push or publication authorized.
