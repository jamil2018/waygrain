# ADR-003 — Product-specialist investigation study (design only)

Status: evaluation design amendment for G08; no production schema or MCP contract change.

Waygrain's desired product role is an investigator, resolver and source pointer across accepted specs, workflows, human knowledge and app observations. The capture-only G05/G07 studies did not measure this broader hypothesis; their failed efficiency gates remain historical evidence.

A future claim model should retain source ID/type, revision, applicability, authority, citations, acquisition time and freshness uncertainty. Keep superseded sources and contradiction/resolution history. Product policy may apply beyond one browser role/origin; observed UI evidence keeps strict capture scope. Documented intent, attributed human report, test report and agent inference cannot be promoted to observed or test-verified backend facts. Open questions record the material gap, known evidence, requested authority, response attribution and remaining uncertainty.

The coding agent should investigate conflicts, ask focused questions when material knowledge is missing, and leave concise cited answers plus useful next-source pointers. Deterministic storage need not add a separate reasoning service. General source ingestion and durable question/claim handling remain a production design gap: G08's source/owner/packet adapter is a synthetic evaluation prototype, not an implemented Waygrain feature.

G08 compares reuse of an actual investigator packet against fully capable ordinary source notes with identical acquired owner/app evidence. Report investigation preparation separately; synthetic owner replies are simulations and three related worlds do not qualify human adoption, another real application or Claude/Cursor. Public release remains HOLD. No migration or runtime implementation is authorized by this amendment.
