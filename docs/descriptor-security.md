# Local descriptor isolation boundary

The supported demo is a single-user synthetic loopback service. Its scope selector chooses among trusted preconfigured contexts; it is not production authentication. Project/app IDs come from configuration. Caller-supplied role, grant, project or app fields cannot expand a route's authority. The separate author listener provides knowledge writes; the reader exposes evidence/source reads and scoped local conversation persistence only. The embedded target adapter itself receives a read-only evidence client and explicit registered elements, never a store or host-action API.

Before provider access, retrieval filters exact environment/version/role/tenant/state, including explicit unknowns. Unknown values are not wildcards. The provider receives a frozen bounded plain-data package. It never receives foreign source markers, store/DOM/tool handles or raw unsupported questions. Source inspection, including retained historical descriptor revisions, uses the same authorization and bounded claim/source closure. Incompatible source IDs return generic errors without titles or excerpts. Responses use `no-store`; scope changes clear panel/history/source nodes and discard late results.

Conversations bind principal and every identity/scope dimension. Context snapshots prevent mutable-host aliasing; authorization is checked before history projection and again after generation. Source revisions and turn ordinals are checked atomically before appending. Old answers are historical context, not evidence. Fabricated prose, citations, evidence classes, missing/conflict omissions and injected tool fields fail validation and are not stored. Bounded omissions remain explicit and cannot establish a reconciliation.

All authored/imported source text remains untrusted data rendered with DOM `textContent`; source instructions and markup are never executed. Explicit source import is knowledge authoring, not permission or code verification. Host form values are not collected; only the owned product-question textarea is read by clarification. Diagnostics return fixed codes and omit source/question bodies. Tests use synthetic sentinels, no credentials or real customer records, and retain no screenshots, traces, browser profiles or raw host snapshots.

W20's API corpus covers all 11 configured scopes, project/app/environment/null-scope forgeries, cross-scope source/history reads, provider-citation forgery and private raw-question disk checks. The real-browser corpus covers hostile import → preview/commit → documentation/source/question rendering, hidden-node cleanup after scope change and zero application activation. Escape now dismisses pending/persistent hover summaries, including late responses and summaries caused by Details focus restoration. Broader accessibility and the complete acceptance journey are W21; no full WCAG, universal host, arbitrary provider sandbox or public-release qualification is implied.
