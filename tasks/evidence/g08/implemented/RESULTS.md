## Interpretation and design gap

The prototype demonstrates useful cross-source investigation: obscure admin policy, supersession, test scope, simulated human clarification, UI/spec conflict and unknown production facts can be organized and answered by fresh agents. It does not establish an efficiency win over fully capable notes. Variation is small and shares one core policy; raw notes already receive all actual acquired knowledge. Ten answers share each batch/context;180 are not independent trials. Timing includes worker/host contention; a quality check also ran during the first investigation group. Fixtures remain static during reuse; no automatic changed-source detection or real-human reply latency tested.

Current production Waygrain still lacks arbitrary document/claim/question ingestion. Source indexing, owner routing and packet query are study-only adapters; no shipped product-specialist feature or schema migration. knowledge_search labels returned rows agent_packet_claim, overwriting original per-claim kind instead of retaining it in a separate field. Original packet keeps documented/human_reported/observed types and work prose maintained distinctions, but typed retrieval metadata and packet-only semantic support remain unqualified. Deterministic stdio probe verifies exact packet transfer, absent raw packet endpoint, source-path rejection and cleanup; it is not model performance evidence.

One bounded follow-up candidate, unselected: define and qualify a durable source-backed policy claim plus an attributed owner-question/resolution record and compact retrieval contract, preserving source revision/citations, original evidence type, applicability and unresolved conflicts.
