## Baselines and retained evidence

Cold has no priming. Warm/changed use identical scripted version-one priming of five scoped screen observations (Members admin/viewer, Settings admin/viewer, detail admin). Notes and Waygrain retain identical sanitized captures including scope/time/coverage; browser-only does not retain them. Priming is itemized and fully billed, including browser calls and retention work. No scripted task-window observation, evidence projection or refresh is supplied. Every task starts a fresh model session on Home. Changed cases have version two and an equally visible revision signal; the agent must choose navigation/snapshot/refresh before relying on obsolete facts.

Priming contains captures only; there are no graph annotations or prose notes, so priming annotation cost is zero rather than hidden. Notes search returns full matching captures, whereas Waygrain search returns summaries followed by evidence reads; this deliberate practical stronger-notes asymmetry is reported. Notes support case-insensitive search (including empty-term enumeration), full read and free-text write with supporting IDs. Waygrain supports explicit ingestion, lexical capture queries and structured evidence retrieval. Current task snapshots can be retained on request. Stored executable targets are excluded. This workload measures capture-memory reuse and bounded UI journeys, not benefits from rich preverified flow graphs. No manual answer preparation or curated knowledge advantage.

## Scoring and decisions

Open prose answer plus free-text factual claims, each citing observation IDs; no answer-value enum or oracle is given. Hidden oracle in the assessor checks expected subject/value, cited screen/role/version/coverage and actual observed state. Independent review checks prose semantic entailment, unsupported additions, omissions and contradictions; merely matching IDs is insufficient. All failures/timeouts/invalid responses remain in the allocated denominator. Score action sequence and observed final state separately from driver receipt success. Changed applicability requires version-two evidence before relevant actions and in final grounded claims; reading old memory alone cannot pass.

Report independently measured per-session total latency; residual host time after subtracting setup/priming is explicitly an approximation including CLI startup, final serialization and server cleanup, not an exact task window or pure inference measurement; setup, priming, model/host wall time, tool timings, cleanup, total time; browser logical operations (including open/bootstrap/navigation/snapshot/click/close); knowledge calls; input/output and cached-input tokens; retained notes or DB/WAL/coordination bytes; success; unsupported claims; wrong attempted/dispatched actions; and freshness failures. Internal mapper/CDP operations and provider hidden costs are unmeasured. Model/CLI drift is recorded. Common schema/server orchestration is itemized as harness overhead where not charged to an arm; all per-arm setup and cleanup is billed. Host wall time includes startup/model/tool use; pure provider inference latency is unavailable and must not be invented.

Compute distributions and within-task/arm medians, then equally weighted task medians, preserving all rows. Compare warm browser calls and either total time or measured tokens against the stronger baseline per metric, with notes explicit and browser-only wherever stronger. Require >=20% browser-call reduction AND >=20% time or token reduction, no success/grounding regression or additional wrong actions, seeded change detection before obsolete use, and <=15% cold total overhead or measured repeated-use break-even. Zero-call denominator cannot prove percentage improvement. Report task-window metrics separately; never erase priming/lifecycle costs. Missing tokens stay null/unmeasured. No break-even claim unless supported by measured setup and repeat costs. A valid study can be verified with a FAILED/UNMET gate verdict.
